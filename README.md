# Kaleidoscope AI - Decompose & Reconstruct

Kaleidoscope AI is an advanced system designed for software ingestion, analysis, and mimicry. It leverages graph theory, quantum simulation, and decentralized AI nodes to understand and reconstruct software from various formats, including binaries and source code.

## Key Features

- **Software Ingestion & Reconstruction**: Analyze and decompile software into specifications and reconstructed versions.
- **Quantum Simulation**: High-fidelity simulation of quantum operations for enhanced pattern recognition.
- **Decentralized AI Nodes**: Self-organizing computational units for distributed analysis.
- **Unified API**: Fast and robust API built with FastAPI for seamless integration.

## Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/kaleidoscopeAI/decompose.git
   cd decompose
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Install external tools (Optional)**:
   For full binary analysis capabilities, install `radare2`, `ghidra`, and `retdec`.

## Usage

Start the system using the launcher:
```bash
python launch.py
```

Access the API documentation at `http://localhost:8000/docs`.
